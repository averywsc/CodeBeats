Toolbox: every command you can use
bpm(n)
Set the tempo, 50 to 200.
loop(beats)
How many beats before the song repeats.
kick(beat)
Bass drum on a beat. Beat 0 is the start; 0.5 is halfway to beat 1.
snare(beat)
Snare drum.
hat(beat)
Hi-hat.
note(name, beat, length)
Play a note such as "C4" or "F#3". Length is in beats.
chord([names], beat, length)
Play several notes at once.
transpose(note, n)
Move a note up (or down, with a negative number) by n semitones.
makeScale(root, type)
List the 8 notes of a “major” or “minor” scale.
sound(wave)
"sine", "triangle", "square" or "sawtooth". Applies to notes after it.
JavaScript glossary
variable
A named box that holds a value. let can change later; const stays fixed.
string
Text inside quotes, like “C4”.
number
A value you can calculate with, like 120 or 0.5.
operator
A symbol that calculates or compares: + - * / % ===
array
A list in square brackets. Position 0 is the first item.
object
Named values grouped together, read with a dot: song.tempo
function
A named recipe you write once and call whenever you like.
loop
Repeats code. for counts; forEach visits each array item.
if / else
Runs code only when a condition is true.
bug
A mistake in code. Error messages tell you where to look.
Music theory cheat sheet
Major scale
0 2 4 5 7 9 11 12 (semitones from the root)
Minor scale
0 2 3 5 7 8 10 12
Major chord
0 4 7: bright and happy
Minor chord
0 3 7: darker and sadder
Intervals
3 minor third, 4 major third, 5 perfect fourth, 7 perfect fifth, 12 octave
Note lengths
1 = quarter note, 0.5 = eighth, 0.25 = sixteenth (in beats)
Octaves
C4 is middle C. Each octave up doubles the frequency.
